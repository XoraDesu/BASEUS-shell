# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in BASEUS, please report it responsibly.

**Do not** open a public GitHub issue for security vulnerabilities.

Instead, contact the maintainer directly through the communication channels listed in the repository profile.

## Scope

BASEUS is a desktop shell. Security considerations include:

- credential handling;
- secret exposure;
- privilege escalation;
- unsafe command execution;
- configuration injection.

## Response

The maintainer will acknowledge reports and work toward a resolution. Timelines depend on severity and complexity.
