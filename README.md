# BASEUS

BASEUS is a personalized Linux desktop shell built with Quickshell for Hyprland.

> Simple for the user. Powerful underneath.

BASEUS combines a restrained wabi-sabi visual identity with expressive motion, contextual surfaces, deep personalization, and an optimization-first architecture.

## Status

BASEUS is currently in its fresh-start foundation phase. The repository's source of truth is being finalized before implementation proceeds.

## Design

BASEUS is intentionally not a generic “modern Linux rice”. Its design language is treated as project identity. See `MASTER.md`, `DESIGN.md`, and `ANTI-SLOP.md`.

## Platform

BASEUS requires Hyprland, not Arch. Arch and Nix are first-class environments. The long-term installer goal is adaptive Linux support where Hyprland and required capabilities are available.
