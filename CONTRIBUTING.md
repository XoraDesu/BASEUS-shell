# Contributing to BASEUS

BASEUS is open source and accepts written contributions through GitHub issues and pull requests.

## Product Direction

The project has a single maintainer/project owner with final authority over direction. A contribution is not automatically a product decision.

## Design Changes

Significant changes to BASEUS visual identity require a Design Proposal before implementation. Explain:

- problem
- proposed change
- why existing design is insufficient
- affected surfaces
- motion/interaction implications
- accessibility implications
- performance implications
- how the change fits MASTER/DESIGN/ANTI-SLOP

## Pull Requests

Keep changes focused. Do not bundle unrelated redesigns into implementation fixes.
